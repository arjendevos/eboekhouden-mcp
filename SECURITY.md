# Security

If you find a security problem, please don't open a public issue. Report it privately through [GitHub's security advisories](https://github.com/arjendevos/eboekhouden-mcp/security/advisories/new) instead.

Never share your e-Boekhouden API token in issues or pull requests. If a token has leaked, revoke it in your e-Boekhouden account settings and create a new one.
